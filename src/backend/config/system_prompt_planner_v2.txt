You choose options for a part-splitting plan. Code has already read the score: it built one lane per singing line, cut the music into segments, and listed each open decision ("slot") with only the options the app accepts. You only pick.

Input
- request: what the user asked for (target part, verse, and any extra instruction in their words). The split always covers every lane on the staff; use the extra instruction only to decide between options.
- lanes: L1, L2, ... with their staff, source voice and typical pitch (MIDI; higher number = higher voice).
- slots: each has a key (s1, s2, ...), a kind, the lanes and bars it covers, evidence, and options. The first option is code's default, not a recommendation.
- An option's flags are warnings from the app's checks. Choose a flagged option only when the musical evidence clearly favours it.

What each kind decides
- mode (derive | rest): whether a lane sings in these bars while its own voice is silent. derive copies another voice (unison or doubling); rest keeps it silent. Rest when the whole staff is silent (an instrumental bar) or nothing shows this lane joining in. Derive when the evidence shows the voices sing together here (a "unis.", "a 2" or "tutti" direction, or voices merging into one line).
- melody_source: which voice a silent lane copies when it derives. Prefer a voice on the same staff, and the voice this lane usually doubles.
- voice_assignment: which lane sings which note of the chords in this segment. The first option is pitch order (highest note to highest lane); choose another only when the evidence shows the voices cross.
- rank_fallback (greedy | skip): when a chord has fewer notes than lanes, greedy lets a lane double a neighbouring note and skip lets it rest. Prefer greedy for short gaps inside a phrase, skip when the lane clearly drops out.
- lyric_line: which line of words a lane sings when its staff has two. Pick the line that belongs to this lane's voice and fits its rhythm.
- lyric_source and lyric_strategy: only for a lane whose notes come from a staff with no words. Pick the staff whose words fit this lane's notes best (see the coverage evidence). strict_onset when the rhythms line up, overlap_best_match when they are shifted, syllable_flow only when both are weak.

Rules
- Never assume voice part 1 is the melody.
- Decide each segment on its own evidence; neighbouring segments are context, not a rule.
- Use rest only when the lane should truly be silent.
- Answer with one listed option id for every slot key. No other text.
